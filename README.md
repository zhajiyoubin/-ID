# 提取小红书用户 ID

这是一个用于批量提取小红书用户 ID 的网页工具。

## 功能

- 提取标准小红书主页链接中的用户 ID
- 支持带分享参数的主页链接
- 支持 `xhslink.com` 短链接
- 短链接会自动跟随跳转，再从目标主页提取用户 ID
- 支持一次粘贴多条链接，每行一条
- 支持 Markdown 链接、表格符号和反斜杠转义字符
- 自动显示成功数量和输入总数，例如 `190/200`
- 解析失败时输出 `null`，保证结果与输入逐行对应
- 结果区域支持滚动，适合处理大量链接
- 提供管理员诊断信息，列出失败链接和失败原因
- 记录短链接解析日志，包括原始链接、HTTP 状态码、最终跳转地址和失败原因

## 支持的链接格式

标准主页链接：

```text
https://www.xiaohongshu.com/user/profile/697456570000000021023fe7
```

带参数的分享链接：

```text
https://www.xiaohongshu.com/user/profile/66ab6899000000000b031a55?xhsshare=CopyLink
```

小红书短链接：

```text
https://xhslink.com/m/1SzKuMrTqtS
```

短链接解析成功后，会先跳转到类似下面的主页地址，再提取用户 ID：

```text
https://www.xiaohongshu.com/user/profile/6745ec620000000001000409?xsec_token=...
```

## 启动方法

在项目目录执行：

```bash
node server.js
```

看到服务启动后，在浏览器打开：

```text
http://127.0.0.1:8787/
```

不要使用 `localhost.com` 或 `www.localhost.com`。

## 使用方法

1. 在输入框中粘贴链接，每行一条。
2. 点击“提取 ID”。
3. 在结果框中查看提取结果。
4. 点击“复制全部结果”复制结果。
5. 如果出现 `null`，点击“管理员诊断”查看失败详情。

## 结果说明

结果会严格按照输入顺序逐行输出：

```text
697456570000000021023fe7
null
6745ec620000000001000409
```

右上角的统计数字表示成功数量和输入总数。例如 `190/200` 表示输入 200 条，成功解析 190 条。

## 日志

短链接和后端解析请求会写入项目根目录的 `resolve.log`。日志包含：

- 解析时间
- 原始链接
- HTTP 状态码
- 最终跳转地址
- 找不到用户 ID 的原因
- 请求异常信息

`resolve.log` 已加入 `.gitignore`，不会被提交到仓库。
